CPS — Услуги и сервисы

О проекте

Учебный проект по созданию адаптивной веб-страницы для компании, предоставляющей услуги по ремонту и обслуживанию техники.

Используемые технологии:

HTML5
CSS3
Flexbox
Media Queries
Responsive Design
Адаптивность

Страница адаптирована для следующих размеров экранов:

Mobile — от 320px
Tablet — от 760px
Desktop — от 1120px

Как запустить проект:

Склонировать репозиторий.
Открыть папку проекта в VS Code.
Открыть файл index.html в браузере.
